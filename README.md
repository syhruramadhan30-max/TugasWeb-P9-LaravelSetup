# Tugas Rutin 9 — Setup Laravel

Repositori ini disusun untuk memenuhi **Tugas Pertemuan 9 (TR 9) Mata Kuliah Pemrograman Web**. Proyek mencakup instalasi Laravel via Composer, konfigurasi basis data MySQL di phpMyAdmin, manajemen rute kustom, pengiriman data dinamis array ke Blade views, pembuatan Controller & Model melalui Artisan CLI, integrasi Tailwind CSS CDN, dan implementasi route parameter dinamis.

---
